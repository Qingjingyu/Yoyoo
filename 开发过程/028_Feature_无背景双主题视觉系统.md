# 028 Feature - 无背景双主题视觉系统

> 日期：2026-08-11
> 范围：V0.11
> 状态：功能实现并完成本地全量验收

## 背景

旧界面依赖雨夜城市图片建立氛围。它在深色模式有辨识度，但正文对比度、不同
尺寸裁切和浅色模式都被一张位图绑定，也让会话产品更像展示页而不是可长期使用
的 IM 工作空间。本轮目标不是换另一张图片，而是把高级感抽象为可维护的视觉系统。

## 关键决策

- 浅色、深色是同一套产品的两种环境状态，共享布局、间距、字体、圆角和交互。
- 组件只消费 `surface`、`text`、`border`、`accent`、`status`、`shadow` 等语义
  Token，不在组件中分别维护两份颜色。
- 大结构保持安静、平整；毛玻璃只用于输入框、菜单、浮层和确实悬浮的控件。
- 首页、会话、设置都移除场景图片及图片专用遮罩；数字生命 Orb 只保留在 Live
  模式，并保留柔和光晕而不是示意图式同心线。
- 主题入口放在低频设置页，支持跟随系统、浅色、深色；选择持久化到本机。
- 首屏脚本在 React hydration 前解析主题，避免浅色闪成深色或产生 hydration
  不一致；跟随系统时监听操作系统主题变化。

## 否掉的备选

- 给旧夜景图片提亮后复用：仍然无法解决浅色模式、裁切和正文可读性耦合。
- 为浅色和深色复制两套样式：后续每个组件都要双份维护，视觉会持续漂移。
- 直接复制普通白色/黑色 IM：开发更快，但会丢失 Yoyoo 的材质层级和数字生命
  辨识度。
- 在一级导航加入永久主题按钮：主题是低频设置，会占用高频操作位置。

## 实现范围

- 新增主题偏好模型、Provider、首屏脚本和设置页分段选择器。
- 建立完整 light/dark 语义 Token，并迁移首页、会话、设置、响应式导航和 Orb
  预览页。
- 删除产品页面的城市背景资源引用与图片遮罩，不删除历史资源文件，便于回滚。
- 新增主题解析、持久化、系统监听、设置交互和跨页面浏览器验收。
- 没有新增依赖，没有数据库迁移，没有 API 或 Agent 协议变化。

## 四态与可访问性

- 原有 loading、empty、error、success 状态继续使用语义色，并在两种主题下保持
  文字或图标提示，不只依赖颜色。
- 保留可见键盘焦点、`prefers-reduced-motion`、移动端安全区和最小触控尺寸。
- 已人工检查 `1440x900`、`1024x768`、`390x844`、`320x568`；最小尺寸下
  首页、会话和设置无横向溢出、标题遮挡或输入框与底部导航重叠。
- 生产预览浏览器控制台人工检查为 0 error、0 warning。

## 剩余限制

- 外部真实 YOS/Codex live 测试需要本机服务与显式开关，本视觉迭代不会自动
  发送外部消息。
- 当前是本地实现与本地验收，尚未推送或部署生产。
