# 030 Feature: 光学毛玻璃材质系统

## 背景

V0.11 已完成无背景双主题，V0.12 已把对话页整理成可长期阅读的旗舰界面，
但界面材质仍接近普通的实色后台：浅色缺少冰雾玻璃的光学边缘，深色的结构层与
内容层也不够容易区分。

本轮目标不是重新设计信息架构，而是在不降低可读性的前提下，为浅色和深色建立
同一套可复用的光学毛玻璃规则。

## 关键决策

- 玻璃只用于导航、框架、输入和临时浮层；时间线与消息内容保持实底。
- 浅色使用冰雾玻璃，深色使用烟熏玻璃，两者共享同一套语义角色和模糊等级。
- 玻璃质感由半透明填充、18-32px 背景模糊、上亮下暗的边缘反射和分级阴影共同构成。
- 强调色继续只表达选中、焦点、在线、运行、成功与主操作，不作为装饰照明。
- 桌面和移动端复用同一材质 token，不新增背景图、字体、UI 库或运行时依赖。

## 否掉的备选

- **全页面玻璃化**：长对话会失去稳定阅读面，层级也会相互竞争。
- **重新加入城市背景或生成图**：会让产品质感依赖素材，并破坏用户确认的纯色方向。
- **使用渐变光斑、HUD 网格或持续动画制造未来感**：容易变成装饰性科幻，且增加视觉疲劳。
- **只给浅色单独写一套样式**：会造成双主题漂移，后续组件无法复用材质规则。

## 实现范围

- `src/styles/tokens.css`：新增导航、面板、控件、浮层、边缘、模糊、饱和度和阴影 token。
- `src/styles/home.css`：共享主导航使用导航玻璃。
- `src/styles/conversation.css`：会话栏、顶部栏、输入框、详情/搜索抽屉和菜单使用对应玻璃层级。
- `src/styles/responsive.css`：移动端底部导航继承同一光学体系。
- `e2e/theme.spec.ts`：验证关键玻璃表面的透明度、模糊与阴影，同时锁定实底阅读面。

没有改动组件树、交互流程、API、数据库、身份、文件或 Agent 协议。

## 影响与回退

影响范围限于共享导航和对话页的视觉材质。若需要回退，只需恢复本轮玻璃 token、
