# 027 Feature - ID 寻址与标准会话列表

> 日期：2026-08-10
> 范围：V0.10
> 状态：功能实现并完成本地全量验收

## 背景

现有房间、成员和消息已经具备稳定 UUID，但产品表面仍混合静态 Agent
快捷入口和真实会话，外部 Agent 也缺少可查询的授权目录与主动投递入口。
名称可修改或重名，因此不能承担执行寻址。

## 已确认决策

- 人、AI、群聊、私聊和消息的实际操作全部使用不可变 ID。
- 所有消息发送到 `room_id`；`principal_id` 用于创建私聊、成员管理和
  房间内提及。
- 发送者由 AI Card、Agent Gateway 或用户会话鉴权得出，禁止请求体冒充。
- 会话删除仅隐藏当前成员列表项，不物理删除共享历史；新活动可使其重现。
- 左侧只显示真实会话，顶部只保留搜索和打开右侧详情栏的更多按钮。

## 否掉的备选

- 按中文名称或自然语言猜目标：重名、改名和多语言会导致误投。
- 浏览器本地置顶：无法跨设备，也无法支持未来多人状态。
- 物理删除房间：会破坏共享消息、文件、Agent 运行和审计事实。
- 新建第二套会话 ID：现有 UUID 已是稳定主键，重复身份源会增加漂移风险。

## 验收边界

- 数据迁移、目录、Agent 主动发送、个人列表状态和 UI 必须分别先有失败测试。
- 不改首页，不新增依赖，不修改已应用迁移，不实现自然语言自动路由。
- 完成后补充具体文件、测试命令、结果和剩余风险。

## 当前实现

- 迁移 `012_addressable_conversations.sql` 为房间增加用途，并为成员增加
  个人置顶和隐藏时间；已应用迁移保持不变。
- Agent Gateway 新增授权目录和按 `room_id` 主动发送入口。发送者只从
  Bearer 凭据推导，重复请求由 `Idempotency-Key` 收敛；同一键对应不同
  发送者、正文、提及、回复、线程或附件时明确返回 `409`，不会误用旧结果。
- 目录声明当前 Agent 在每个房间内允许的发送、提及、回复和线程动作；停用
  工作区、停用 Principal、失效工作区成员和失效房间成员均不能继续寻址。
- 左侧合并为一个真实会话列表；支持右键、键盘菜单、触屏长按和行内更多
  入口，可置顶、取消置顶、重命名、软隐藏和归档。
- 顶部移除静态 Agent 状态卡，仅保留搜索和三点详情；详情栏展示可复制的
  `room_id`、用途、成员、文件和低频设置。
- 首页未修改，没有新增或删除依赖。
- 最后一个可见活动会话不能被隐藏；即使历史数据或并发状态造成零会话，页面
  也会显示可恢复的新建状态，而不是误报连接中断。

## 剩余风险

- “从列表移除”是成员个人软隐藏，不是共享删除；新消息会让它重新出现。
- 当前产品仍没有联系人一级入口，因此新私聊由现有身份/通讯录能力创建，
  会话一旦存在就只按稳定房间 ID 继续使用。
- 真实外部 YOS/Codex live 测试需要本机服务和显式环境开关，本轮本地门禁
  不会自动发送外部消息。
- 当前是本地已验证代码，尚未提交、推送或部署到生产环境。
